# Green Bank Project
<a href="https://green-bank-next-js.vercel.app/" target="_blank">Live Demo</a>

This project is a web application for a green bank, built using React, Next.js, and Tailwind CSS.  It utilizes various UI kits and tools to provide a user-friendly interface.

## Introduction

The Green Bank Project aims to provide a platform for users to manage their finances with a focus on environmentally friendly initiatives.  This project is a simplified version and does *not* include responsive design.

-   **React:**  A JavaScript library for building user interfaces.
